# 사업가의 사자성어

경영·협상·투자 현장에서 자주 쓰는 사자성어 508개를 한 장씩 뽑아 보며 공부하는 웹 페이지입니다.

- **사자성어 뽑기**: 버튼을 누르면 무작위로 한 개가 나옵니다(‹ › 버튼, 방향키로 순서대로 넘기기).
- **글자 뜻풀이**: 네 글자 각각의 훈과 음(예: 漁 고기잡을 어).
- **이야기**: 유래와 배경을 스토리텔링으로 풀었습니다.
- **실무에서는**: 상가·창업·중개·투자 상황에 대입한 활용 예.
- 분류 8개(리더십·전략·위기·사람·신뢰·성장·기회·판단), 검색, 퀴즈 모드, "외웠어요" 체크(브라우저에 저장).

## 실행
`index.html`을 브라우저로 열면 됩니다. 별도 설치가 필요 없습니다.

## 데이터
`data/01.js` ~ `data/11.js`에 `[한글, 한자, 훈음(|구분), 뜻, 이야기, 실무 활용, 분류]` 형식으로 들어 있습니다.
수정 후 `node tools/validate.js`로 글자 수, 음 일치, 중복을 검사하세요.

# 미세스머니 웹사이트 (`mrsmoney/`)

동탄역 공인중개사 미세스머니(꼭티비채널) 브랜드 사이트입니다. `mrsmoney/index.html`을 브라우저로 열면 됩니다.

- 화면 폭을 채운 워드마크가 스크롤하면 헤더 로고로 줄어드는 하우스 브랜드형 레이아웃
- 매물 컬렉션(아파트 / 상가·식당·카페 / 단독건물), 이번 주 매물 가로 스크롤(현재 예시 데이터)
- 현장 체크리스트, 동탄 생활권 지도, 꼭티비채널 링크, 상담 요청서(복사해서 문자로 보내는 방식)
- 사진은 `mrsmoney/images/`에 있습니다. 매물은 스크립트의 `LISTINGS` 배열에서 바꾸고(`img`에 사진 경로), 푸터의 중개사무소 등록번호를 채워 주세요.
